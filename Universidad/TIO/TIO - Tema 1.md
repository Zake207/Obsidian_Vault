# TIC en las organizaciones
Conjunto de herramientas y recursos tecnológicos que mejoran el funcionamiento de la organización.
Van desde las más básicas (gmail) hasta las más complejas (ia, big data...)

Las **Tecnologías emergentes** son innovaciones en sus primeras etapas, hay que tener especial cuidado pues su impacto no es del todo conocido, se usan para tratar de obtener ventajas sobre el resto.

## Posibles beneficios
+ Aumento en la productividad
+ Mejora en las comunicaciones
+ Aumento de la colaboración
+ Mejora la toma de decisiones
+ Fomento de la innovación

## Elementos
Unos de los elementos son grupos de personas que se organizan y trabajan bajo una serie de normas, de manera coordinada para cumplir ciertas metas y objetivos.

## Clasificación
En base a diferentes conceptos
+ **Localización** (local, regional, nacional o internacional)
+ **Tamaño** (pequeña, mediana , grande)
+ **Finalidad** (con/sin ánimo de lucro)
+ **Propiedad** (privada o pública)
+ **Tipo** (producción o servicios)

Poseen diferentes atributos como sus departamentos, burocracia, formalización, etc...
# Conceptos básicos
## TIC
**Suite**: Conjunto de herramientas para un ámbito concreto
**TIC**: Conjunto de herramientas informática, este beneficia la productividad, comunicación y optimiza el trabajo.
## Organizaciones
Sistema social de personas que interactúan para lograr un objetivo común, puede ser de carácter social, económico, etc...
## Tecnologías y Técnicas
+ **Técnica** Conocimiento/destreza que te permite usar la tecnología. Comprende procedimientos, normas y protocolos. Las técnicas son transferibles de un individuo a otro. Se resume como *la habilidad para usar la tecnología*
+ **Tecnología** Instrumento que te permite hacer algo. Conjunto de técnicas para crear bienes o servicios.

Ambos tienen un objetivo compartido para satisfacer los intereses de los sujetos, poseen un carácter socialmente estructurado.

## Datos y Sistemas de información
+ **Datos** Hechos recogidos sin procesar
+ **Información** Datos procesados (dotados de relevancia)

La calidad de estos se miden en base a su precisión (ACCURATE):
+ Precisa
+ Completa
+ Compatible
+ Orientada al usuario
+ Relevante
+ Accesible
+ Oportuna
+ Fácil de usar

Un sistema de información es un conjunto de datos interrelacionados, cuyo cometido es captarlos, almacenarlos y operarlos. Se organizan en cinco capas dependientes de las anteriores desde el hardware hasta el usuario.

HARDWARE  ->  PLATAFORMA  ->  BLOQUES DE DATOS  ->  MIDDLEWARE  ->  APP

1. Elementos físicos que proporcionan capacidad de computo, almacenamiento y red
2. Sistema operativo que puede ser de escritorio, servidor o Cloud
3. Motores que guardan de manera persistentes los datos (SQL, NoSQL, Big Data, Master Data Management)
4. Comunica aplicaciones y gestiona procesos
5. Ejecuta el proceso de negocio de la aplicación interactuándo con el usuario

Los sistemas de información apoyan decisiones, coordinación y control además de analizar problemas y crear productos nuevos. Pueden ser automatizados.

Un sistema de información cuentan con recursos humanos que son especialistas y los usuarios finales del mismo.

**Procedimientos - Información - Usuarios - Equipo**
+ Procedimientos: marcados por los directivos, no siempre reguladas.
+ Información: Se adapta al usuario
+ Usuario: Trabajan con la info para realizar sus actividades
+ 

Usan ordenadores monitores y demás junto con medios para guardar los datos, además de recursos software como servicios en la nube.

**Equipo de soporte** parte visible del SI, comunica y procesa el almacenamiento de información.
### Recursos y tecnologías
Los recursos humanos son los especialistas y los usuarios finales.

Los recursos de hardware son aquellos dispositivos que procesan la info: maquinas para operar y los medios de guardado

Los recursos de software son las instrucciones de procesamiento de información

Los datos son la materia prima de los SI, se organizan en Bases de datos y Bases de Conocimiento

Los recursos de telecomunicaciones son las redes y sus componentes relacionados para interconectar todo.
## Empresa
Infraestructura para desarrollar sus actividades (crear productos ofrecer servicios), comercialización óptima y controlar el empleo de los recursos.

**La estrategia de negocio es vital**

Un sistema de información empresarial coordina la información necesaria para llevar a cabo las actividades de la empresa.
