# Arquitectura de un sistema de información
Se refiere a la estructura, el comportamiento y demás aspectos de un sistema de información.
Usa diferentes principios:
+ Separación de intereses
+ Single Responsability
+ DRY
+ Minimizar el diseño inicial

Se suelen usar patrones para describir la arquitectura sin entrar en demasiados tecnicismos.
+ SOA es una arquitectura orientada a servicios, 
+ Bus de mensajes
+ Cliente servidor

En el desarrollo se desarrollan diferentes capas, la más importantes: Presentación, Servicio, Negocio, Persistencia.

Una aplicación se divide en microservicios que son más simples autonomos e independientes, mejora la escalabilidad horizontal, permite tecnología políglota
+ Contenedores (Docker)
+ Orquestación (Kubernetes)
+ APIs
+ Practicas DevOps

## Modelo de cadena de valor
Se dividen las actividades de la empresa en:
+ **Actividades primarias**
+ **Actividades de apoyo**

## Sistemas para inteligencia de negocios
Mejoran la toma de decisiones, la capacidad de análisis y reducir el tiempo, mejorar el seguimiento
