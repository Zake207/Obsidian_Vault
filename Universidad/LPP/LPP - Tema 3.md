# Programación funcional
## Características
+ NO admite variables, todas deben ser constantes
+ Las funciones NO pueden tener efector lateral o secundario
+ Se deben hacer uso de funciones de orden superior
+ NO hay bucles
+ Currying (convierte las funciones con solo un argumento en compuesta) *preguntar*
+ Lazy evaluation (no llama a la funcion hasta estar en el punto donde se necesita)

En los bloques se cambia el valor de las variables definidas fuera, al salir del ambito de un bloque de código, esa variable retorna al valor que tenia en un origen.
