# Introducción
Una aplicación web se ejecuta en un navegador y ofrece un servicio donde:
+ Todo el software se almacena en un servidor
+ Permite una interacción con el usuario
Existen diferentes tipos (progresivas, ecommerce, meta-aplicaciones)

Las app web tienen todas las ventajas de las aplicaciones nativas y las páginas web además de alguna que otra desventaja

Comprenden dos partes:
+ **Backend** Lógica, seguridad y comunicación de servicios
+ **Frontend** Visualización del navegador

Un sistema centralizado colapsa en caso de fallo en una de sus partes

Un sistema descentralizado evita un colapso total del sistema en caso de error en alguna de las partes.

Un sistema distribuido permite que nunca se colapse el sistema en caso de fallo en una de sus partes, este pude mejorarse por hardware, mejorando la distribución y por software.

Un balanceador de carga aumenta la escalabilidad, actúa como puerta de entrada de todas las solicitudes, redistribuyendo la carga y monitoriazándola, sigue diferentes criterios de balanceo de carga:
+ Round Robin
+ Nº peticiones
+ Balanceo persistente
+ Configurable
