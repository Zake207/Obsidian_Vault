# Introducción
Este proyecto consiste en una aproximación en miniatura de un proyecto real que me permitirá ampliar mi portafolio y practicar mis habilidades de programador.

La idea principal consiste en una página web que permita almacenar una serie de registros sobre especies fósiles, estos registros constarán de la capacidad no solo de especificar datos básicos como el nombre y especie del espécimen sino de tener asociado un fichero que el usuario podrá personalizar con información propia. Cada usuario tiene sus ficheros aislados del resto a modo de sistema de notas personalizadas para el ámbito de la aplicación.

La idea del proyecto es fácilmente extrapolable a cualquier caso real donde se quiera llevar un registro de diferentes especies flora o fauna.

Me permitirá llevar a cabo un simulacro de un proyecto de una aplicación fullstack y me permitirá aprender conocimiento nuevo útil dentro del oficio. Cabe destacar que el uso de inteligencia artificial será limitado y se usará únicamente como guía sobre lo que deba desarrollar principalmente en el proyecto o con dudas muy específicas sobre el código. No se pretende practicar vibe-coding con este proyecto ni nada parecido.

# Idea
La idea principal para el MVP del proyecto es la de una aplicación fullstack, donde el usuario se registre, y pueda acceder a sus registros para poder editarlos y modificarlos. No hay gestión por parte de administradores sobre la rigurosidad de la información aportada.

Dentro de la herramienta podemos contar con las siguientes entidades: User (cliente de la aplicación), Registro(el cual está asociado a su usuario y contiene toda la información) e imágen (para almacenar las imágenes asociadas al registro)
